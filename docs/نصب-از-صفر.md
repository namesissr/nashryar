# نصب نشریار از صفر — از نصب داکر تا بالا آمدن پنل

این راهنما فرض می‌کند یک سرور خالی **Ubuntu 22.04/24.04** دارید و می‌خواهید نشریار را با داکر
اجرا کنید. کل مسیر حدود ۱۵ دقیقه است.

---

## گام ۱ — اتصال به سرور و به‌روزرسانی

```bash
ssh root@IP-سرور
apt update && apt upgrade -y
```

## گام ۲ — نصب داکر

```bash
# نصب رسمی داکر (Engine + Compose)
curl -fsSL https://get.docker.com | sh

# بررسی نصب
docker --version
docker compose version
```

اگر با کاربر غیر root کار می‌کنید:

```bash
usermod -aG docker $USER
# یک بار خارج و دوباره وارد شوید
```

> **سرور ایران/تحریم:** اگر ایمیج‌ها دانلود نشدند، یک میرور رجیستری بگذارید:
>
> ```bash
> cat > /etc/docker/daemon.json <<'EOF'
> { "registry-mirrors": ["https://docker.arvancloud.ir"] }
> EOF
> systemctl restart docker
> ```

## گام ۳ — انتقال پروژه به سرور

از سیستم ویندوزی خودتان (PowerShell) — `node_modules` و `.next` لازم نیست بروند:

```powershell
scp -r C:\ContentHub\nashryar root@IP-سرور:/opt/nashryar
```

یا اگر پروژه را روی گیت گذاشته‌اید:

```bash
git clone آدرس-مخزن /opt/nashryar
```

سپس روی سرور:

```bash
cd /opt/nashryar
rm -rf node_modules .next          # اگر همراه scp آمده باشند
```

## گام ۴ — تنظیمات محیط

```bash
cp .env.example .env

# ساخت کلید تصادفی نشست‌ها
openssl rand -base64 48
```

فایل `.env` را ویرایش کنید (`nano .env`):

```bash
SESSION_SECRET="کلیدی-که-همین-الان-ساختید"
APP_URL="https://hub.دامنه-شما.com"    # آدرس نهایی نشریار
```

> `DATABASE_URL` را دست نزنید — داخل داکر خودکار روی `/app/data/nashryar.db` تنظیم می‌شود.

## گام ۵ — بیلد و اجرا

```bash
cd /opt/nashryar
docker compose up -d --build
```

بار اول ۳ تا ۵ دقیقه طول می‌کشد. بررسی:

```bash
docker compose logs -f nashryar
# باید ببینید:  ⏳ آماده‌سازی دیتابیس…  →  🚀 اجرای نشریار روی پورت 3100  →  ⏰ زمان‌بند فعال شد
curl -I http://127.0.0.1:3100/login    # باید 200 بدهد
```

دیتابیس در `/opt/nashryar/data/` و تصاویر در `/opt/nashryar/uploads/` می‌مانند و با
بیلدهای بعدی از بین نمی‌روند.

## گام ۶ — دامنه و Nginx با TLS

```bash
apt install -y nginx certbot python3-certbot-nginx

cat > /etc/nginx/sites-available/nashryar <<'EOF'
server {
    listen 80;
    server_name hub.YOURDOMAIN.com;

    client_max_body_size 10m;

    location / {
        proxy_pass http://127.0.0.1:3100;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
EOF

ln -s /etc/nginx/sites-available/nashryar /etc/nginx/sites-enabled/
nginx -t && systemctl reload nginx

# گواهی رایگان TLS
certbot --nginx -d hub.YOURDOMAIN.com
```

رکورد DNS دامنه (`hub.YOURDOMAIN.com` → IP سرور) را قبل از certbot ثبت کرده باشید.

## گام ۷ — ورود اولیه

مرورگر: `https://hub.YOURDOMAIN.com`

- ایمیل: `admin@nashryar.local`
- رمز: `Nashryar!2026`

**بلافاصله بعد از ورود:** از بخش **نویسندگان** یک مدیر با ایمیل واقعی خودتان بسازید، با آن
وارد شوید و حساب پیش‌فرض را حذف کنید (یا رمزش را عوض کنید).

## گام ۸ — اتصال چهار سایت

برای هر سایت (ارزینو، چارتینو، فیلمینو، بلوپال):

```bash
# ۱) یک کلید محرمانه بسازید
openssl rand -hex 24

# ۲) روی سرور همان سایت، در فایل .env اضافه کنید:
HUB_SECRET=کلید-ساخته-شده

# ۳) سرویس سایت را ری‌استارت کنید (نمونه):
cd /opt/سایت && docker compose up -d --build backend   # یا api
```

نکته‌های تک‌به‌تک:

| سایت | بعد از تنظیم HUB_SECRET |
|---|---|
| ارزینو | `docker compose up -d --build backend` |
| چارتینو | `docker compose up -d --build api` |
| بلوپال | مایگریشن وبلاگ خودکار اجرا می‌شود؛ `docker compose up -d --build backend frontend` |
| فیلمینو | اول مایگریشن: `bash scripts/migrate.sh` سپس `docker compose build api web && docker compose up -d api web && docker compose restart edge` |

سپس در نشریار → **سایت‌ها**، برای هر سایت:
1. آدرس عمومی و آدرس API (معمولاً همان دامنه سایت) را وارد کنید،
2. همان کلید محرمانه را بگذارید،
3. **«آزمایش اتصال»** بزنید — باید سبز شود.

از این لحظه انتشار، زمان‌بندی، آمار و تنظیمات وبلاگ همه فعال است. 🎉

## به‌روزرسانی نسخه

```bash
cd /opt/nashryar
# فایل‌های جدید را منتقل کنید (scp یا git pull)، سپس:
docker compose up -d --build
```

دیتابیس و تصاویر دست نمی‌خورند؛ تغییرات جدول خودکار با `prisma db push` اعمال می‌شود.

## پشتیبان‌گیری

همه‌چیز همین دو پوشه است:

```bash
tar czf nashryar-backup-$(date +%F).tar.gz -C /opt/nashryar data uploads .env
```

یک کران روزانه هم بگذارید:

```bash
crontab -e
# 30 3 * * * tar czf /root/backups/nashryar-$(date +\%F).tar.gz -C /opt/nashryar data uploads .env
```

## عیب‌یابی

| مشکل | راه حل |
|---|---|
| کانتینر بالا نمی‌آید | `docker compose logs nashryar` — معمولاً `SESSION_SECRET` خالی یا `.env` ناقص است |
| «آزمایش اتصال» خطای 503 | روی سایت مقصد `HUB_SECRET` تنظیم نشده یا سرویس ری‌استارت نشده |
| «آزمایش اتصال» خطای 401 | کلید نشریار با کلید `.env` سایت یکی نیست |
| تصاویر مقاله روی سایت‌ها نمی‌آیند | `APP_URL` باید آدرس عمومی نشریار با https باشد و از اینترنت باز باشد |
| پورت 3100 از بیرون باز است | نباید باشد! کامپوز فقط به `127.0.0.1` بایند می‌کند؛ فایروال را هم چک کنید: `ufw allow 80,443/tcp && ufw enable` |
| زمان‌بندی اجرا نمی‌شود | لاگ باید «⏰ زمان‌بند نشریار فعال شد» را نشان دهد؛ ساعت سرور را چک کنید: `timedatectl set-timezone Asia/Tehran` |

## اجرای محلی روی ویندوز (بدون داکر)

برای تست روی همین سیستم فعلی:

```powershell
cd C:\ContentHub\nashryar
npm install
npm run setup     # فقط بار اول
npm run dev       # http://127.0.0.1:3100
```
