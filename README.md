# نشریار — هاب مرکزی نگارش و انتشار محتوا

پنل واحد برای نوشتن مقاله، تحلیل سئو و انتشار مستقیم روی وبلاگ چهار سایت:
**ارزینو، چارتینو، فیلمینو و بلوپال** — بدون نیاز به ورود جداگانه به هر سایت.

---

## زمان‌بندی خودکار

زمان‌بند هر ۶۰ ثانیه داخل خود سرور اجرا می‌شود (`src/instrumentation.ts`) — نه در dev و نه در
production پروسه جداگانه‌ای لازم نیست. دو مکانیزم دارد:

1. **زمان مشخص:** در ویرایشگر، تاریخ و ساعت را انتخاب و «زمان‌بندی» را بزنید؛ مقاله در همان
   لحظه خودکار منتشر می‌شود.
2. **صف انتشار خودکار:** مقاله را با «افزودن به صف انتشار خودکار» وارد صف سایتش کنید و در
   بخش **زمان‌بندی** برای هر سایت برنامه بچینید:
   - تعداد مقاله در روز (۱ تا ۲۴) — مثلاً ۳ مقاله در روز
   - نحوه پخش: «پخش یکنواخت در بازه» (مثلاً ۹ تا ۲۱) یا «ساعت‌های ثابت» (مثلاً 09:00,14:00,19:30)
   - روزهای هفته (مثلاً فقط شنبه تا چهارشنبه)
   - بازچینش صف با دکمه‌های بالا/پایین، مشاهده نوبت‌های امروز و شمارش منتشرشده‌ها

   اگر سرور در ساعت نوبت خاموش بوده باشد، با روشن شدن، نوبت‌های عقب‌افتاده همان روز جبران
   می‌شوند؛ سهمیه روزانه هرگز رد نمی‌شود. اگر انتشار به دلیل قطعی سایت مقصد شکست بخورد،
   مقاله در صف می‌ماند و تیک بعدی دوباره تلاش می‌کند.

   دکمه «اجرای الان» همان تیک را دستی اجرا می‌کند. همه ساعت‌ها به وقت محلی سرور است.

## راه‌اندازی

```bash
npm install
npm run setup     # ساخت دیتابیس SQLite + داده‌های اولیه
npm run dev       # اجرا روی http://127.0.0.1:3100
```

ورود اولیه: `admin@nashryar.local` / `Nashryar!2026` — **پس از اولین ورود رمز را عوض کنید** (فعلاً از راه دیتابیس: `npx prisma studio`).

## اتصال سایت‌ها (مهم)

هر چهار سایت یک «درگاه دریافت هاب» یکسان دارند:

```
POST   /api/hub/blog          درج/به‌روزرسانی مقاله (بر اساس اسلاگ)
DELETE /api/hub/blog/{slug}   حذف
GET    /api/hub/blog/stats    آمار بازدید
```

همه با هدر `X-Hub-Secret` محافظت می‌شوند. برای فعال‌سازی هر سایت:

1. یک کلید تصادفی بسازید:
   ```bash
   node -e "console.log(require('crypto').randomBytes(24).toString('hex'))"
   ```
2. در فایل `.env` همان سایت مقدار `HUB_SECRET=کلید` را بگذارید و سرویس را ری‌استارت کنید.
3. در نشریار → بخش **سایت‌ها** → همان کلید و آدرس API سایت را وارد و «آزمایش اتصال» را بزنید.

### نکته‌های هر سایت

| سایت | وضعیت وبلاگ | بعد از تنظیم HUB_SECRET |
|---|---|---|
| ارزینو | از قبل داشت — درگاه به `backend/app/routers/hub.py` اضافه شد | ری‌استارت backend کافی است |
| چارتینو | از قبل داشت — درگاه به `server/src/modules/hub/` اضافه شد | بیلد و ری‌استارت api |
| فیلمینو | جدید ساخته شد (ماژول `api/src/blog/` + صفحات `web/app/blog/`) | اول مایگریشن: `bash scripts/migrate.sh` (فایل `011_blog.sql`)، بعد بیلد api و web |
| بلوپال | جدید ساخته شد (`backend/blogRoutes.js` + صفحات React) | مایگریشن `009_blog.sql` هنگام بوت خودکار اجرا می‌شود؛ بیلد frontend |

### قالب محتوا

ارزینو مارک‌داون رندر می‌کند و بقیه HTML؛ نشریار هر دو را در هر انتشار می‌فرستد و هر سایت خودش نسخه درست را برمی‌دارد — تنظیم «قالب محتوا» در پنل فقط جنبه اطلاعاتی دارد.

## استقرار

نشریار باید از سرور سایت‌ها قابل دسترس باشد (برای انتشار) و برعکس (برای نمایش تصاویر آپلودی).
ساده‌ترین حالت: روی همان سرور یکی از سایت‌ها با PM2:

```bash
npm run build
pm2 start "npm run start" --name nashryar   # پورت 3100
```

و در `.env` مقدار `APP_URL` را به آدرس عمومی نشریار تغییر دهید (مثلاً `https://hub.example.com`)
تا آدرس تصاویر مقاله‌ها درست ساخته شود. `SESSION_SECRET` را هم حتماً عوض کنید.
